File names

EkClick always prefers the Classroom attachment title, flags uncertain names, and sanitizes invalid path characters. Review and rename uncertain names in the popup before downloading.

Privacy and browser behavior

EkClick reads links and labels from the open Google Classroom page. It does not send files or account information to a server. Default browser location mode asks the browser to retrieve the Drive URL using its normal signed-in session. Selected folder mode fetches and validates file content inside EkClick.

Default browser location mode uses the browser configured Downloads folder and its usual save-dialog preference. Selected folder mode requires the directory picker and an authorized folder handle.
